Fusing Entire Llama-1B into a Megakernel on GPU

July 29, 2025 2 minutes read
Note
LLM • GPU • AI

Fusing Everything

Kernel launching has become increasingly expensive as the LLM models become more and more complex with many small kernels. A widely-adopted approach to tackle this is fusing kernels into a single one, as well as Cuda Graph.

Megakenel from Hazy Lab is an aggressive attempt to fusing the entire LLM layer into a single kernel to maximize the performance. And here are some notes and findings during playing with this project.

Fusing an entire LLM layer is extremely complex, usually impossible by manual efforts considering the complex dataflow between stages. So we have to introduce some abstraction over the underlying GPU, and the main idea of megakernel is to construct a virtual machine (VM) over GPU, which instantiates a virtual pipeline on GPU:

There are some basic principles of this VM:

  • The VM executes “mega-instruction” – mega as they are actually complex operations, e.g. fused GEMV with RMSNorm, flash attention, etc.
  • Warp-specialized pipeline – each warp separately handles control logic, data dependence, data movement, computation and writeback, and synchronized with each other using mbarrier (purple in the above fig.)
  • Fine-grained data-dependence – data dependence across instructions can be tracked by counters in global memory.
  • Paged share memory – To overlap two instructions on the pipeline, the share memory is divided into 13x16kB pages (for H100), once the prior instruction releases a page, the following instruction can start to copy in. The share memory organization is shown as:
