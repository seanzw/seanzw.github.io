Gem5 x86 ISA Decoder Notes

2020/01/25

Exchange REGM and REG in EmulEnv

EmulEnv always assumes that addReg() will first add reg and then regm. This is fine when specialized with (Vo, Wo). But when specialized with (Wo, Vo), the order of reg and regm is reversed. Be careful here to use the correct register index when defining the macroop.

Maximum Number of Destination Registers

There is a limit on the maximum number of destination registers a static instruction can have (MaxInstDestRegs). In gem5, zmm is represented by eight 64-bit registers. Normal instructions operating on zmm will be broken down into eight microops, each only updates one 64-bit registers. However, this introduces too many microops. To reduce this overhead, we can try to break it into only one microops, which updates all the eight 64-bit registers.

The problem is that MaxInstDestRegs is automatically generated by the ISAParser. It scans through the microop implementation and increments MaxInstDestRegs. We change it to be at least 8 for X86ISA.
